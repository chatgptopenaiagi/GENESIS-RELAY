# Changelog

## 0.1.0 — experimental initial public release

Continues the existing GENESIS RELAY implementation rather than replacing it. Preserves the engineering theory, version 1.0 capsule format, explicit file dispositions, SQLite backup, immutable source evidence, destination receipts and selected-file return/conflict/rollback semantics.

The public candidate removes mandatory author-machine paths, ships the browser interface and trusted receiver, adds a self-contained invented-data laboratory, and provides Python/Linux/Windows distributions with platform-specific verification. Actual build/test/public-download outcomes belong to the release verification files and workflow evidence, not to this change description.

The project was originated and directed by the operator of `chatgptopenaiagi`, with AI-assisted implementation using Codex. Existing GENESIS Relay contributors attribution and MIT notices are retained. Private original deployments, capsules and research remain outside the public release.
