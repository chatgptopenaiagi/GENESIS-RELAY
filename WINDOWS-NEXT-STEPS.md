Start with INSTALL-WINDOWS.md and QUICKSTART.md. The public synthetic demonstration and native executable tests are separate from the private scientific laboratory and from an operator's personal workstation. Consult release verification for the exact tested scope.

Before restoring a real project, record the destination's actual tools, architecture, available space and existing Codex executable/version without copying secret values. Transfer the private capsule through an authorized route, retain its external checksum reference, and use the separately trusted receiver. Inspect executes no project code. Review the native Windows and WSL plans independently, then materialize into a new owned workspace.

Reconstruct destination-compatible dependencies; do not copy Linux ARM64 site-packages. The optional full scientific profile uses Unix locking/resource/process facilities and needs focused native adaptation or an actually verified WSL environment. A demo pass does not qualify that scientific port.

Keep existing Codex executable/authentication/MCP settings and unrelated projects unchanged. Never export authentication to CI. If an authorized Windows Codex session is unavailable, record that specific test NOT_RUN while retaining independent native executable/demo acceptance.
